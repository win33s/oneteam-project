# 기획 (draft v1, 2026-10-01)

> 이 문서는 기획 원문을 정리한 것입니다. 기획이 업데이트되면 이 문서와 `설계.md`, 코드에 함께 반영합니다.

## 배경

- 신입이나 조직문화활동 기획자(엔지니어지만 일정 기간 이 역할을 맡음)가 한 달에 한 번쯤 조직문화활동을 기획한다. 부서원끼리 친해지거나 조직력을 강화하는 게임, MBTI 검사, 회식 기획과 장소 예약 등이다.
- 처음 맡으면 막막하다. 부서가 이전에 어떤 활동을 했는지는 본인이 입사한 이후 내용만 안다.
- 다른 팀·부서에도 같은 역할을 하는 사람이 1~2명씩 있지만, 어디에 가서 어떤 활동을 언제 했는지 공유할 창구가 사내에 없다.
- 그래서 사내에서 동작하는, 부서별 조직문화활동 기획자를 위한 에이전트와 웹사이트를 만든다.

## 기능

1. 날짜 추천 → 투표 생성
   1. 팀원 일정 체크. 후보가 많으면 부서원에게 투표 메일을 자동 발송
   2. 팀 과제 일정 체크
2. 장소 추천 근거
   1. 경비 처리 데이터를 수집해 비슷한 시기 타부서 경비 처리를 레퍼런스로 확인
   2. 사내 블로그 단체 사진 등을 확인, 회식 후 구성원 후기 반영
3. 후기 작성
   1. 날짜·장소 확정 후 참가자에게 후기를 묻는 네이버 폼을 자동 작성
4. 업그레이드
   1. 몇 번 갔는지 확인하고, 중복되는 장소·활동이면 새로운 것도 추천
   2. 추천이 잘 보이도록 첫 화면부터 게임/식당/호텔 등을 보여 주기
   3. 개인 선호 반영: 개인 프로필에 적어 두기, 처음 질문 사항에 옵션으로 포함

## 업무 돕기: 회의비로 처리되는 모든 것의 이력을 긁어 오는 에이전트

1. 레퍼런스를 정리해 옆 부서·타 팀 사례를 참고할 수 있게 한다.
2. 경비 처리, 사진 등 단체활동 관련 정보를 모두 정리해 장단점과 함께 추천한다 (자동화, 코멘트 등).
3. 전체 흐름: 구성원·프로젝트 일정을 긁어 와 날짜를 정함 → 날짜에 맞춰 할 만한 것을 레퍼런스에서 추천 → 리뷰·경비 처리 데이터를 참고해 회식 장소 추천 → 예약 또는 안내 메일 발송 → 회식 후 만족도 조사 폼 자동 발송과 데이터 수집

## 데모 요구사항

- 웹사이트 안에서 동작하는 에이전트 데모로 만든다.
- 부서원 일정 캘린더 연동.
- 사내 ERP 연동: 이미 올라가 있는 경비 처리 기록을 불러온다. 경비 코드(어느 경비를 썼는지, 팀장에게 배정된 돈인지 부서 돈인지), 제목, 경비 품목, 용도, 구입·소비 내역 등. ERP 화면을 크롤링하는 데모가 필요하다.
- 첫 화면: 숙소 앱처럼 블록 카드로 추천이 바로 보인다. 부서가 최근 간 곳, 다른 부서 평점이 좋은 곳, 시기별(벚꽃·가을·겨울 등) 갈 만한 곳. 좌우로 넘기며 클릭해 볼 수 있다.
- 식당 회식이면 식당 예약 사이트(네이버 지도 등)를 바로 열어 주는 단계까지 간다.
- 날짜 후보가 여럿이면 후보를 입력하고 사내 조직도에서 부서원을 선택해 넣으면, 각자에게 날짜 투표 메일이 가고 결과를 실시간으로 볼 수 있다.
- 활동 후 담당자가 ERP에 법인카드 사용 내역을 올리면, 에이전트가 ERP 내용을 긁어 와 부서 조직문화활동 기록으로 자동 등록한다. 담당자에게 기록 업데이트 메일을 보내고, 담당자는 코멘트(좋았다, 별로였다, 어떤 활동을 했는지 등)를 추가할 수 있다.
