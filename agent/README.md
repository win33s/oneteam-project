# 한자리 — 조직문화활동 기획 에이전트 (데모)

부서의 조직문화활동을 처음 맡은 기획 담당자를 위한 에이전트와 웹사이트입니다. 날짜 잡기, 장소 추천, 예약, 안내, 경비 기록 수집, 후기 수집까지 한 흐름으로 이어집니다.

ERP·캘린더·조직도·메일은 모두 **가상(Mock)** 이며, 부서·인물·장소·경비 데이터도 모두 지어낸 값입니다.

## 실행

```bash
npm install
npm start
```

브라우저에서 http://localhost:4000 을 엽니다.

개발할 때는 `npm run dev`를 쓰고 http://localhost:5173 을 엽니다 (화면 수정이 바로 반영됨).

| 명령 | 설명 |
|---|---|
| `npm start` | 화면을 빌드하고 서버 실행 (포트 4000) |
| `npm run dev` | 서버(4000)와 Vite 개발 서버(5173) 동시 실행 |
| `npm run reset` | 데모 데이터 초기화. 서버를 다시 시작하면 새로 생성 |

### Claude API 연동 (선택)

환경변수 `ANTHROPIC_API_KEY`를 설정하고 서버를 시작하면, 첫 화면의 문장 해석과 추천 조언을 Claude가 작성합니다. 없으면 규칙 기반으로 동작합니다.

## 데모 순서

1. **첫 화면**: 우리 부서가 최근 간 곳, 타부서 평점이 좋은 곳, 지금 시기에 갈 만한 곳, 아직 안 가 본 곳이 카드로 보입니다. 화살표로 좌우로 넘깁니다.
2. **새 활동 기획**: 조건을 넣고 조직도에서 부서원을 고른 뒤 "에이전트에게 날짜 추천받기"를 누릅니다.
3. **날짜**: 후보를 여러 개 골라 "투표 메일 보내기"를 누릅니다. "데모: 부서원 3명 응답 받기"를 누르거나, 미응답자 화면 링크로 직접 투표하면 결과가 실시간으로 바뀝니다. "이 날로 확정"을 누릅니다.
4. **장소**: 추천 근거(타부서 경비 기록, 후기)를 펼쳐 보고 "이곳으로 확정하고 안내 메일 보내기"를 누릅니다.
5. **예약**: "예약하기"를 누르면 네이버 지도가 새 탭으로 열립니다.
6. **ERP 등록**: "활동 후 ERP에 경비 등록"을 누르면 가상 ERP 등록 화면이 계획 내용으로 채워져 열립니다. 등록합니다.
7. **자동 기록**: 10초 안에 에이전트가 전표를 감지합니다. 기획 화면이 "기록" 단계로 바뀌고, 메일함에 기록 업데이트 메일이 옵니다. 기록에 코멘트를 남깁니다.
8. **후기**: 메일함에서 받는 사람을 부서원으로 바꿔 후기 요청 메일의 폼을 작성하면 평점이 기록과 추천에 반영됩니다.

오른쪽 위 "에이전트 로그"에서 에이전트가 한 일을 순서대로 볼 수 있습니다.

## 알아 둘 점

- 장소 이름은 가상이므로 예약 버튼은 "지역 + 업종"으로 네이버 지도 검색을 엽니다.
- 후기 폼은 네이버 폼을 대신하는 데모 화면입니다.
- 캘린더와 과제 일정은 서버를 처음 실행한 날짜 기준으로 생성됩니다. 날짜가 많이 지나면 `npm run reset`으로 다시 만드세요.
